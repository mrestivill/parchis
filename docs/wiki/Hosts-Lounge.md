# 🛋️ The Host's Lounge (Customization & Admin)

Did you click "Create Room" or are you the server owner? Congratulations, you are the Host! 

As the Host, you have the remote control for the game room. It is your job to set the mood, adjust the rules, and make sure everyone is having a good time.

## 👑 Server Admin vs. Room Host

There is a big difference between an Admin and a Host!
*   **Room Host:** The person who creates a specific Game Room. They only have power over *that specific room* (starting the game, pausing it, kicking players from their room).
*   **Server Admin:** The very first person to register an account on the entire server automatically becomes the Global Admin. Admins have a special dashboard where they can see all active rooms, ban misbehaving users permanently from the server, and forcefully close any room.

## 🎨 Room Settings & Rules

If you are the Host of a room, look for the "Settings" gear icon before clicking "Start Game". You can tweak the game to fit your group's playstyle. 

Here is a breakdown of what you can change:

| Option | What it does | Why use it? |
| :--- | :--- | :--- |
| **Visual Themes** | Changes the entire color palette of the board (e.g., Dark Mode, Neon, Classic). | Great for playing at night without hurting your eyes! |
| **Turn Timer (Time to Move)** | Adjusts how many seconds a player has to *move their piece* after rolling. | Set to 15s for intense games, or 45s if you are easily distracted. |
| **Roll Timer (Time to Roll)** | Adjusts how many seconds a player has to *click the dice*. | A shorter 10s timer keeps the game moving fast! |
| **Time Bonuses (+ Seconds)** | Grants extra seconds to the clock when a player captures an enemy or reaches the center goal. | Rewards aggressive plays. Capturing someone gives them anxiety while giving you extra time to think! |
| **Allow Spectators** | Toggle if people can join the room just to watch. | Turn off if you want a private game without an audience. |
| **Spectator Chat: Read** | Toggle if Spectators can see what active players are typing. | Turn off if players are discussing private strategies. |
| **Spectator Chat: Write** | Toggle if Spectators are allowed to type messages. | Turn off if spectators are distracting the active players! |
| **Allow Late Join** | Allows players to take over an empty/bot slot *after* the game has started. | Turn on if waiting for a slow friend, but you want to start playing now. |

## 🛠️ In-Game Moderator Tools

Sometimes things get chaotic. The host has tools directly under the chat box or near the timer to control the flow:

> **⏸️ Pausing the Game:**
> Life happens! As the host, you can click the Pause button. This freezes the board and stops all turn timers globally. Click it again to resume when the pizza delivery arrives.

> **👢 Kicking a Player:**
> If someone is being rude, or going AFK too much, the host can kick them from the room. The game will automatically adapt and keep playing without them.

> **🔄 Forcing a Restart:**
> Did someone make a terrible mistake on turn one and they are begging for a do-over? Unlike normal players who can only vote to restart *after the game is fully finished*, the Room Host has veto power! The host can instantly click restart and wipe the active board clean at any moment.
